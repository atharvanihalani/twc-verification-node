Connect a box

start streaming from any NVIDIA GPU machine

Run this on the GPU box (as root if you can). It asks for the site password once, downloads the collector from this node, and installs it so it keeps running.


      
This page is running on localhost, which a remote box can't reach. Run ./tunnel.sh <ssh-port> <user@box> on this Mac first, so the box's 127.0.0.1:18999 leads here.

      
Or: split one box into several pretend nodes (prototyping)
      
Same thing, but it asks for a split like 4+4 or 2+2+4 (up to 4 parts, GPUs assigned in order). One collector process; each part shows up as its own node, <host>-a, -b…, with its GPUs numbered from 0. Running the normal command above turns the split off again.

      

      
Fine for pipeline checks, not evidence: the parts share one clock, one chassis and NVLink (real nodes talk over InfiniBand). See SPLIT_CAVEATS.md.

      

      
Connect a scheduler (Slurm)

      
Run this once per cluster, wherever sbatch works (the controller or a login node). It doesn't need GPUs. Every 5 s it reads Slurm's job table (scontrol show job, read-only) and sends it here; jobs then appear under Slurm jobs. Declare a job with sbatch --comment=declared:pretraining (or inference). No Slurm on the machine? It offers to install a one-box Slurm for testing (needs root + apt).

      

      
Afterwards: python3 ~/.twc-slurm-reporter/slurm_reporter.py status (or once to print what it would send, or uninstall).

      
What install does

      
    
        
  • Copies itself to ~/.twc-collector/ and saves the settings there (owner-only, since they hold the password).
    • 
        
  • Installs nvidia-ml-py if it's missing, in a private venv.
    • 
        
  • Keeps it running with whatever this machine has: systemd (normal Linux machines, needs root), else supervisor (e.g. vast images), else a background restart loop plus a cron @reboot entry.
    • 
      

      
On the box afterwards

      
python3 ~/.twc-collector/collector.py status      # running? last log lines
python3 ~/.twc-collector/collector.py uninstall   # stop and remove

      
The box appears under Live telemetry within a few seconds, named after its hostname (add --host NAME to choose).
