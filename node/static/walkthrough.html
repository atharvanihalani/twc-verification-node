Walkthrough

This walkthrough assumes you have an 8x Nvidia SXM node. If you don't, click here.

1Install everything

Paste this on your GPU box. It installs:

  • The telemetry collector
  • vLLM for inference workloads
  • TorchTitan for training workloads

The script is the same on every box. It also offers an optional Hugging Face login; a read-only token is enough. Everything it prints is kept in ~/.twc-setup/logs/setup.log.

Password: the same one you used to log in to this site.
